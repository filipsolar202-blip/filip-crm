# Ověření verze 2026.09.16-1

Testováno v izolovaném profilu Chrome se smyšlenými klienty. Skutečná klientská data, pošta ani vzdálená Google tabulka nebyly měněny. Referenční vydání: Git commit d332145 (2026.09.15-1).

## Úspěšné kontroly

1. Shoda portfolia, součtů a provizí s referenční verzí na testovacích datech.
2. Přesná shoda HTML klientského přehledu s referenční verzí.
3. Otevření všech 13 hlavních agend s naplněnými daty.
4. Otevření klientských, investičních, penzijních a editačních dialogů.
5. Stažení a samostatné otevření klientského HTML.
6. Stažení a samostatné otevření FKI HTML.
7. Stažení a samostatné otevření HTML investičního scénáře.
8. Oddělená data uskutečněného hovoru a následného úkolu.
9. Vytvoření a úprava klienta v uloženém stavu.
10. Investiční návrh nevytváří dokončený obchod.
11. Podepsané FKI vytváří obchod i propojenou investici.
12. Obnova testovací zálohy zachovává úplné schéma stavu.
13. Pomalá odpověď disku nepřepíše novější úpravu; následuje další zápis.
14. Dokončení aktivity z dashboardu používá společnou akci.
15. Zobrazení při rozměru iPadu 834 × 1112, včetně vizuální kontroly.

Všechny tři HTML výstupy byly také převedeny do PDF pro kontrolu, že tisk vytvoří neprázdný dokument. Nejde o úplnou vizuální kontrolu všech tiskových kombinací. Během průchodu nebyly zachyceny chyby běhu JavaScriptu.

Doplňkově prošlo:

- Kontrola syntaxe, 917 jedinečných aplikačních funkcí, lokálních souborů a absence přepisovacích vrstev.
- Kontrola syntaxe zachovaných samostatných HTML nástrojů, scénářového skriptu a Apps Scriptu.
- Diskové úložiště v dočasné složce: prázdný stav, příloha, zápis, načtení a záloha.
- Google Apps Script s paměťovou náhradou tabulky: vícečástový přenos, metadata, shoda načteného stavu, odmítnutí chybného klíče a neúplného přenosu.
- Kontrola syntaxe tří podpůrných Python skriptů a čistoty změn.

## Meze ověření

Živé připojení Google, Apple Mail a skutečný uživatelský disk nebyly použity. Tablet byl ověřen rozměrem okna Chrome, nikoli na fyzickém iPadu v Safari. Samostatné historické kalkulačky prošly kontrolou syntaxe, nikoli úplným funkčním průchodem. Testovací data nepokrývají každou možnou finanční kombinaci ani všechny varianty Excel exportů. Výsledky tedy neznamenají záruku bezchybnosti každého výstupu za všech okolností.
